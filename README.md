# Convert-video to-still-image
動画を静止画化っぽくするカスタムオブジェクト。  

メディアオブジェクトの動画を静止画化というカスタムオブジェクトとして追加される。  

動画ファイルの場所は自力で指定するしかない。  

静止画にしたい動画を、静止画にしたい時点で分割し、その動画ファイルの"動画ファイル_再生位置_終了値"を"固定する時間(秒)"にコピペすれば、簡単に時間を指定できる。  

各種チェックボックスは、あくまでも大雑把なエフェクトを1発で適用するためのものなので、細かく指定したい場合は普通にエフェクトを付与して、そちらで数値を調整してください。  

これで静止画のように扱える。
